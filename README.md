# Good Life OS — information pages

The public information pages for Good Life OS, a private single-user personal
health dashboard that runs locally on its operator's own computer.

These pages exist because the Oura API requires an application to publish a
privacy policy and terms of use.

- `index.html` — what the application is, what it does today, what is not built yet
- `privacy.html` — how data is collected, stored, used, retained and deleted
- `terms.html` — terms of use

The dashboard itself, its database, its backups and its credentials are **not**
in this repository and are never published. This repository contains only the
pages above and their stylesheet.

The pages load no web fonts, no scripts and no analytics, so reading them makes
no third-party requests.
